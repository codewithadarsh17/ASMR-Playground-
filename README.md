🎧 ASMR Playground
hey guys! so this is a cozy little web project i built just for relaxing sounds, stress relief, and good vibes. basically, it lets u mess around with 6 different interactive tactile toys right inside your browser without needing to install anything heavy.

since i wanted the audio to feel super responsive and smooth, i also built a custom in-browser audio engine using the Web Audio API. it generates all the cozy ASMR sound effects (like keyboard thocks, bubble pops, and slime squishes) completely locally in real time, so there's zero lag and no need for external server calls.

✨ Features
6 Interactive Toys:

Mechanical Keyboard (featuring Thocky, Clacky, and Creamy switch options)

Pop-it Board (satisfying bubbles that actually flip over when fully popped!)

Bubble Wrap (for those classic crunchy runs)

Stretchy Slime (drag it, stretch it, and watch it snap back with realistic physics)

Switch Wall (flip individual switches or send a wave across the board)

Clicky Pen (click it out or push it back in whenever ur bored)

Real-time Audio Engine: generates all sound effects directly in the browser on the fly with no delay.

Cool Hardware-Style Controls: features a working volume knob, sound toggle switch, dynamic joy meter, and a live waveform LCD display.

Fully Responsive Design: built to run smoothly on both desktop setups and mobile screens.

🛠️ Built With
HTML5 / CSS3

Vanilla JavaScript (no annoying frameworks required lol)

Web Audio API (for custom procedural sound synthesis)
